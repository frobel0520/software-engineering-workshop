HANDOFF / CHECKLIST12

部署前，確認這七件事

  1. 01Tenant ID 指向正確目錄
  2. 02Client ID 屬於正確 App Registration
  3. 03Secret Value 只在後端，且可輪替
  4. 04Redirect URI 與環境完整相符
  5. 05Logout 同時處理 App 與 Entra session
  6. 06Authority 的 tenant 與帳號範圍一致
  7. 07Metadata 與 Token 版本一致
